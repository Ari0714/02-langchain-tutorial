# LangChain Tutorial

This repository is a small Python learning project focused on LangChain and model invocation examples. It demonstrates how to install LangChain, load environment variables, and call LLM providers such as DeepSeek and OpenRouter from Python.

## Project overview

The project contains a few lightweight scripts used for experimentation:

- `main.py` — a default sample script generated by the IDE
- `_01_summary/` — notes and environment checks for LangChain basics
- `_02_model/` — example model calls using different providers
- `requirements.txt` — Python dependencies for the project
- `.env` — local environment configuration for API keys and model endpoints

## Tech stack

- Python 3.x
- LangChain
- DeepSeek integration via `langchain_deepseek`
- OpenRouter integration via `langchain_openrouter`
- `python-dotenv` for environment variable loading

## Setup

1. Create a virtual environment:

```bash
python -m venv .venv
```

2. Activate it:

- Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

- Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Create a local `.env` file (if not already present) with your provider credentials:

```env
DEEPSEEK_API_KEY=your_deepseek_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

If you want to use OpenRouter as well, add the matching key and settings for that provider in the same way.

## Run the examples

Check the installed LangChain version:

```bash
python _01_summary/_01_langchain_test.py
```

Invoke a DeepSeek model:

```bash
python _02_model/_01_invoke_deepseek.py
```

Invoke an OpenRouter-backed model:

```bash
python _02_model/_02_invoke_openrouter.py
```

## Notes

- This is a learning/demo project, not a production-ready application.
- The examples rely on external API keys, so keep your `.env` file private.
- The scripts are intentionally small and focused on understanding how LangChain connects to model providers.
